# Glosario operativo

| Término | Uso en Deprepo |
| --- | --- |
| Modelo | Sistema que genera predicciones o respuestas; identificar versión y proveedor al comparar |
| Harness | Capa de instrucciones, tools, memoria, políticas y ejecución alrededor del modelo |
| Agente | Sistema que selecciona pasos y usa resultados del entorno para avanzar hacia un objetivo |
| Workflow | Secuencia o grafo de pasos definidos; puede incluir modelos sin delegarles todo el control |
| Tool | Interfaz de lectura o acción; su disponibilidad no implica autorización ilimitada |
| Skill | Procedimiento reutilizable que puede incluir instrucciones y scripts |
| Memoria durable | Registro corregible que se desea conservar entre sesiones y proveedores |
| Retrieval / RAG | Recuperar información relevante para construir contexto; no garantiza que la fuente sea correcta |
| Routing | Elegir modelo o proveedor según tarea, costo y restricciones |
| Worktree | Directorio de trabajo vinculado a un repositorio Git; no es aislamiento de procesos |
| Evals | Pruebas con criterios explícitos para medir desempeño y restricciones |
| Alignment | Pregunta de si objetivos y conducta del sistema corresponden a lo deseado, bajo condiciones definidas |
| Interpretabilidad | Investigación de representaciones y mecanismos; no equivale a demostrar conciencia |
| Meta-work | Trabajo dedicado a mantener el sistema con el que se trabaja |
| ZDR | Zero Data Retention; requiere verificar alcance y condiciones actuales de cada proveedor/endpoint |
