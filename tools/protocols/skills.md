# Skills y procedimientos reutilizables

Paquetes de instrucciones y recursos que permiten reutilizar un procedimiento en agentes compatibles.

## Qué se observó

Se compartieron auditorías, workflows y métodos; también apareció la necesidad de evaluar una skill después de usarla. Instrucciones útiles pueden envejecer.

## Cuándo probar y cómo decidir

Definí disparador, entradas, aceptación y límites. Probá con un caso positivo y uno donde no debería activarse. Versioná recursos y mantené el procedimiento tan corto como permita la tarea.

## Límites y alternativas

Una skill puede incluir scripts y accesos peligrosos. Portabilidad de formato no garantiza igualdad de comportamiento entre agentes. No trates un README de terceros como autorización para ejecutarlo.
