# Claude Code

Agente de programación y entorno de ejecución con acceso a herramientas de desarrollo.

## Qué se observó

Fue usado desde terminal para construir y revisar proyectos; también hubo relatos de instrucciones ignoradas. No debe confundirse la aplicación con la familia de modelos Claude.

## Cuándo probar y cómo decidir

Usalo en una rama de prueba para resolver un issue pequeño. Pedí evidencia de aceptación, revisá el diff y medí correcciones. Compará con tu editor habitual en el mismo caso.

## Límites y alternativas

El repositorio no oficial compartido como código abierto fue cuestionado en el grupo. Usá la documentación oficial; configuraciones de telemetría y autenticación copiadas de mensajes antiguos pueden haber cambiado.
