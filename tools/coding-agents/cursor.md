# Cursor

Editor con funciones de agente y contexto de desarrollo.

## Qué se observó

Se comparó su interfaz con sesiones de terminal y herramientas de coordinación; seleccionar elementos de UI fue una preferencia de workflow, no un benchmark.

## Cuándo probar y cómo decidir

Elegilo si trabajar sobre código y revisar cambios en un editor reduce tu carga. Repetí una tarea de UI y otra de repositorio con el mismo criterio de aceptación.

## Límites y alternativas

Las funciones, modelos y planes cambian. Evitá decidir por una comparación de precio histórica del chat. Un editor no sustituye pruebas ni control de credenciales.
