# OpenCode

Entorno de coding agents orientado a terminal y múltiples proveedores.

## Qué se observó

Apareció en discusiones de BYOK, cuotas y routing; el proyecto previo go-model-router aplica reglas específicas a un proveedor.

## Cuándo probar y cómo decidir

Inspeccioná configuración y proveedores disponibles sin copiar claves al repositorio. Probá un caso sintético antes de habilitar cambios y verificá qué política se aplica al fallback.

## Límites y alternativas

Una suscripción de otro producto no implica permiso para reutilizar sus tokens. No publicamos reglas universales sobre OAuth, precios ni retención.
