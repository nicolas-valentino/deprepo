# Cline

Agente de programación con integración en flujos de desarrollo y proveedores de modelos.

## Qué se observó

Se reportó uso de Cline con OpenRouter para probar diferentes modelos. Ese relato confirma una experiencia, no calidad uniforme entre combinaciones.

## Cuándo probar y cómo decidir

Compará dos modelos sobre el mismo issue y conjunto de tools. Registrá las llamadas necesarias y el costo completo hasta que el cambio pase aceptación.

## Límites y alternativas

La selección de proveedor puede modificar retención, latencia y compatibilidad de tools. Validá límites y permisos del cliente antes de darle un repositorio con datos privados.
