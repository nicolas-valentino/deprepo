# Logseq

Plataforma de conocimiento personal con edición por bloques y relaciones.

## Qué se observó

Varios participantes mantenían allí notas manuales. En septiembre se reportaron dificultades tras cambios hacia un almacenamiento basado en base de datos. Es una experiencia de versión/configuración, no pérdida universal de exportación.

## Cuándo probar y cómo decidir

Inspeccioná el formato efectivo de tu instalación y hacé una restauración/exportación de prueba. Compará búsqueda y edición con el sistema que usás hoy.

## Límites y alternativas

No afirmamos que todas las versiones actuales sean Markdown nativo. Revisá compatibilidad del grafo, plugins y exportaciones antes de migrar.
