# La evidencia importa más que el entusiasmo

Una mención, una demo y un resultado reproducido representan niveles diferentes de confianza.

## Aprendizaje de la comunidad

En marzo de 2026 una supuesta apertura del código de Claude Code fue cuestionada porque el repositorio compartido no era oficial. En otros momentos se discutió si demos editadas permitían inferir latencia. El aprendizaje generalizable es verificar procedencia y condiciones.

## Aplicación

Clasificá cada afirmación: documentación de capacidad, experiencia con contexto, benchmark controlado o hipótesis. Para comparar sistemas, fijá tareas, versión, presupuesto, criterios y número de intentos. Una lista de estrellas no mide utilidad ni seguridad.

## Límites y posiciones

Una fuente primaria puede tener incentivos comerciales y no ofrece replicación independiente. Un desacuerdo entre usuarios puede surgir de tareas o configuraciones diferentes. No conviertas la preferencia personal en un ranking global.
